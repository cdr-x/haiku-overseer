# Purpose

Systematically extract and synthesize key concepts, algorithms, and techniques from multiple research papers to inform technical implementation decisions.

## Overview

This skill enables comprehensive analysis of research documentation by reading multiple files, identifying core ideas and algorithms, and evaluating their relevance to active development projects. It's useful when integrating academic research into production systems or understanding the theoretical foundations of new features.

## Instructions

### Step 1: Identify Document Collection
Locate the directory containing research papers or technical documentation. Note the file paths and formats (e.g., .mhtml, .pdf, .md).

### Step 2: Read All Files
Read each document in the collection sequentially to capture complete content.

### Step 3: Extract Key Elements
For each document, identify and extract:
- Core ideas and concepts
- Algorithms and methodologies
- Mathematical formulas and equations
- Unique techniques or approaches

### Step 4: Analyze Applicability
For each extracted element, assess:
- Relevance to your current project/system
- Implementation feasibility
- Potential impact on existing architecture
- Integration complexity

### Step 5: Synthesize Results
Compile findings into a structured summary that connects theoretical concepts to practical applications.

## Output Format

Structured extraction report containing:
- Document summaries with key ideas
- Algorithm descriptions with formulas
- Applicability analysis for the target system
- Integration recommendations and technical considerations
